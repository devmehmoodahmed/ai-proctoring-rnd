POC #6 — Candidate Side (Simulate Events)

Standalone R&D prototype. Simulates the events POC #1–4's real detectors would produce, so we can test event delivery and the review workflow without needing a live camera/mic here. See README.md for the test matrix.

What this does & how to test it
  • This page pretends to be a candidate's browser sending proctoring alerts. Open dashboard.html in another tab or window first — that's where the alerts show up.
  • Click any button below to send one simulated event to the dashboard.
  • Watch it appear on the dashboard almost instantly, and try acknowledging/confirming/dismissing it there.
  • Try opening the dashboard in two separate tabs — both should receive the same events at the same time.
