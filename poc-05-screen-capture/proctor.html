POC #5 — Proctor Screen Viewer

Standalone R&D prototype. Live, view-only screens of every connected candidate, received peer-to-peer over WebRTC. No remote control, no recording. See README.md for the test matrix.

What this does & how to test it
  • Open candidate.html in another window (or several, one per simulated candidate) and share a screen there.
  • Each candidate shows up here as a tile; the screen appears automatically once they share. Click a tile to view it full-screen and check whether text is readable.
  • Glass-to-glass latency is measured automatically when the candidate turns on the latency probe and that window is visible on the shared screen.
  • Screen events (share stopped, wrong surface, second monitor) appear in the log below as they happen.
