POC #5 — Candidate Screen Share

Standalone R&D prototype. Shares your screen live with a proctor over WebRTC (peer-to-peer). Nothing is recorded or stored anywhere — the server only relays connection setup messages. See README.md for the test matrix.

What this does & how to test it
  • Open proctor.html in another window first — that's where your screen shows up.
  • Click Share entire screen and pick a whole screen (not a window or tab). Picking a window/tab is rejected, on purpose.
  • Stop sharing using the browser's own "Stop sharing" bar — the proctor should be told immediately.
  • Turn on the latency probe and keep this window visible on the screen you're sharing — the proctor page reads it to measure real end-to-end delay.
