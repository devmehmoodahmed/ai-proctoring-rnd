POC #3 — Phone / Object Detection

Standalone R&D prototype. All inference runs locally in this browser tab via MediaPipe Object Detector (WASM) — no video frame is ever sent to a server. Not wired to any production app. See README.md for how to run the test matrix and where results get recorded.

What this does & how to test it
  • This watches your webcam and flags when it sees a phone.
  • Click Start camera, then try: holding up a phone, placing it on the desk in view, holding it near your face, and holding it at an angle.
  • Also try "decoy" objects it might confuse for a phone: a calculator, a TV remote, a wallet, a water bottle, or just your empty hand — this is the main thing we need to learn from testing.
  • Watch the status message above the video and the event log below — each row shows what was detected and for how long.
  • Every object the camera recognizes is boxed and labeled on screen (not just phones) — useful for seeing what a decoy object gets mistaken for.
  • A very quick, split-second appearance should not log an event — only sustained phone visibility should.
