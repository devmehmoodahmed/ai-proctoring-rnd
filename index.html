AI Proctoring R&D

Proof-of-concept track for AI-assisted exam proctoring. Each POC below is standalone and privacy-first — all inference runs on-device, nothing is uploaded. See R&D.md for the full architecture/research document.

  • POC #1 — Face Presence / Out-of-Frame / Multiple Faces implemented

    MediaPipe Face Detector (BlazeFace). Detects whether a candidate's face is present, out of frame, too far, or if multiple faces appear.

  • POC #2 — Gaze / Head-Pose ("Looking Away") implemented, tested

    MediaPipe Face Landmarker. Detects sustained head-turn away from the screen via yaw/pitch, with a calibration step.

  • POC #3 — Phone / Object Detection implemented, tested

    MediaPipe Object Detector (EfficientDet-Lite0). Detects a phone in view, and shows what decoy objects (calculator, remote, wallet) get mistaken for.

  • POC #4 — Speaking / Voice Activity Detection implemented, tested

    Silero VAD (on-device). Detects when the candidate is speaking versus silent — no transcription, no audio ever recorded.

  • POC #6 — Real-Time Events → Proctor Dashboard awaiting test pass

    Node.js + Server-Sent Events. Simulated alerts flow from a candidate page to a live proctor dashboard with an acknowledge/confirm/dismiss review workflow. Needs node server.js — see its README.

  • POC #7 — Evidence Rolling-Buffer Recording awaiting test pass

    MediaRecorder rolling buffer. Saves a short local video clip (before/after a trigger) instead of recording continuously. Needs node server.js — saves real video to local disk, see its README first.

Run each POC from its own folder — see that folder's README for instructions.
