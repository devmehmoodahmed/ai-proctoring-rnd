POC #4 — Speaking / Voice Activity Detection

Standalone R&D prototype. All audio processing runs locally in this browser tab via an on-device voice activity model (WASM) — no audio is ever recorded or sent to a server. Not wired to any production app. See README.md for how to run the test matrix and where results get recorded.

What this does & how to test it
  • This listens to your microphone and tells you when you're speaking versus silent — useful for flagging if a candidate is talking when they shouldn't be.
  • Click Start microphone, then try: talking normally, staying completely silent, background noise with no talking (typing, tapping the desk, music), a quick cough or sneeze, and someone else talking in the room.
  • Watch the status message and the level bar above the event log, and the event log below — each row is one completed speech segment with its length.
  • A very brief sound (a cough, a tap) should show up as "discarded" rather than logged as speech — that's expected, not a bug.
  • Nothing is ever recorded or saved — only whether speech happened and for how long.
